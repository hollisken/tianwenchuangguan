# 天问闯关 · 少年天文之旅 🚀

一款为"天文学知识已经超过很多大人的孩子"设计的天文闯关答题游戏。
纯网页实现：**安卓/iOS 手机浏览器、平板、电脑浏览器**都能玩，双击 `index.html` 即可离线运行。

## 怎么玩

- **最简单**：直接双击 `index.html`（无需安装任何东西，可离线）。
- **手机上**：把整个文件夹发给手机（或放到网盘/本地服务器），用浏览器打开 `index.html`，
  然后在浏览器菜单里选"添加到主屏幕"，就像一个 APP。
- **本地服务器**（可选）：`python3 -m http.server 8000`，手机访问 `http://电脑IP:8000`。

> 进度自动保存在浏览器的 localStorage 里（换浏览器/清缓存会丢进度）。

## 第三阶段 · 万物之理（`stage3/` 文件夹）

前两阶段通关后的**基础物理与科学思维篇**，专为二三年级小学生设计——重点解决"基础数字/物理知识不够、容易靠死记或猜"的问题，打开 `stage3/index.html` 即可：

| 项目 | 内容 |
|---|---|
| 定位 | 不再单纯加难度，而是"补地基"：12 关 = 12 堂基础物理课（运动与速度、力与引力、能量、热与温度、光、波、原子、电与磁、时间与历法、压力与平衡、尺度与数字、科学家怎样思考） |
| 📖 出发小课堂 | 每关首次进入弹出一堂"小课堂"，用生活例子（闪电雷声、吸管、跷跷板、折纸上天）把本关需要的数学/物理基础先讲一遍 |
| 💡 提示系统 | 每题可点"看提示"，只给思考方向、绝不给答案；**零提示三星通关**有专属成就"纯净推理"，鼓励独立思考 |
| 🧱 基础小课堂 | 解析升级为双段式：先讲前置概念（如"动能与速度的平方"），再讲本题的道理——答错也能把地基补上 |
| 防猜设计 | 题目全部改写为推理题/情景题（"月亮为什么掉不下来""冰淇淋与溺水有什么关系"），选项设计成常见误解；答案位置已程序化均衡 |
| 存档 | 独立存档键 `twcg_save_v3`，与前两阶段进度互不影响 |

三个阶段都支持键盘作答（A/B/C/D 或 1/2/3/4，回车下一题），电脑手机通用。

## 游戏内容（第一阶段）

| 项目 | 数量 |
|---|---|
| 闯关站点（关卡） | 12 关（每关 10 题，关内由易到难） |
| 题目总数 | 120 题（单选，从月相一路考到哈勃常数危机） |
| 星空知识卡 | 24 张（每关通关掉落 2 张，图鉴收集） |
| 成就 | 12 枚 |
| 称号 | 8 级（见习观星者 → 宇宙大师） |
| 无尽模式 | 通过 3 关后解锁：随机 15 题、3 颗心、冲最高分 |

机制：3 颗爱心，答错扣 1 颗并立刻弹出**讲解**（讲解本身就是新知识）；
0 错 = 3★、1 错 = 2★、≥2 错 = 1★；答错的题自动进入**错题本**，复习答对即清除。
电脑上支持键盘：`A/B/C/D` 或 `1/2/3/4` 选择，回车下一题。

## 如何加题 / 改题

题库与引擎完全分离。照抄现有格式在 `js/questions-a.js` / `js/questions-b.js` 里添加即可：

```js
{
  id: 'L01Q11',            // 全局唯一，建议按 关号-题号 命名
  tag: '月球',             // 界面上显示的知识标签
  diff: 2,                 // 难度 1~3
  q: '题干……？',
  opts: ['选项A', '选项B', '选项C', '选项D'],
  ans: 2,                  // 正确答案的下标（0~3），注意让分布均匀
  exp: '解析：先讲为什么，再送一个冷知识。'
}
```

注意：
- `ans` 的位置请打乱分布（不要都放同一个位置），已有校验脚本可查；
- 每关保持 10 题左右、难度由浅入深；
- 新关卡对象需要 `cards: [i, j]` 指向 `facts.js` 里两张卡的下标；
- 改完可跑一次校验（见下）。
